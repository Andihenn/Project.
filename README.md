### Multi Launcher

Eine Windows-Python-Anwendung zum Verwalten gespeicherter Konten sowie zum Starten und Überwachen mehrerer Roblox-Clients.

- [Multi Launcher öffnen](./Multi%20Launcher.html)
- [Multi Launcher.py herunterladen](./Multi%20Launcher.py)
- [Python-Quellcode ansehen](./Multi%20Launcher.py)

## Multi Launcher starten

Die Datei **Multi Launcher.py** ist Python-Quellcode und ausdrücklich keine EXE-Datei. Zum Ausführen benötigst du eine kompatible Python-Installation unter Windows.

```powershell
python -m pip install -r requirements.txt
python "Multi Launcher.py"
```

Microsoft Edge und der installierte Roblox Player werden von den Funktionen der Anwendung vorausgesetzt.

## Sicherheit

Die Anwendung verarbeitet Anmeldedaten und Sitzungsinformationen. Bewahre diese Daten privat auf, nutze das Programm nur auf einem vertrauenswürdigen Gerät und teile niemals Passwörter, Cookies oder Sitzungsdateien. Gespeicherte Passwörter und Cookies werden unter Windows mit DPAPI geschützt.
